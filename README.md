## 👋 About me

I am a backend and infrastructure developer focused on real production systems.  
My main area of interest is hosting infrastructure: billing platforms, game server panels, VPS/VDS services, Linux servers, automation, DDoS protection and high-load backend services.

I am building **EGN**, an infrastructure ecosystem for Minecraft hosting, VPS/VDS, dedicated servers, DDoS protection and AI-powered server management.

I like projects where code is connected with real servers, real users and real responsibility.
